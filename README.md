## Introducción

El proyecto constituye un sistema de gestión de turnos para un hospital/clinica que centralice la disponibilidad de los turnos de los profesionales de salud. Esto con el fin de mejorar la gestion de turnos que se realizan de forma manual, como por ejemplo planillas, agendas fisicas y llamadas telefonicas.
La propuesta busca aportar valor en cuestiones tales como reducir el tiempo administrativo en coordinacion manual, la eliminacion de errores en la reserva.
